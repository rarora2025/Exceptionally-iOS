# Exceptionally — mobile (Expo SDK 54)

This app runs on **Expo SDK 54** (React Native 0.81, React 19.1). It was
downgraded from SDK 57 because 57's native deps needed Swift 6.2 (Xcode 16.4+)
and the App Store Expo Go didn't support it. Stay on SDK 54 unless the local
Xcode is upgraded. Check exact APIs at https://docs.expo.dev/versions/v54.0.0/
before writing native/Expo code.

## Running it
- Simulator: `npm run ios` (uses `scripts/ios.sh`; avoid `expo start --ios`,
  which needs Accessibility permission for osascript).
- Device dev build: `npx expo run:ios --device <udid>` (signs with team
  QU24NSL7DR; needs the iPhone unlocked). Loads JS from Metro over WiFi.

## Stack notes
- Auth + data: Supabase (`src/lib/supabase.ts`, `src/state/auth.tsx`,
  `src/lib/db.ts`). Public keys live in `mobile/.env` (gitignored). Schema in
  `supabase/schema.sql`.
- Design tokens in `src/theme.ts`; screens are a `state.screen` switch in
  `src/Router.tsx` (see `src/state/store.tsx`).
- `ios/`+`android/` are gitignored and regenerated by prebuild — don't commit
  them, and re-apply signing (DEVELOPMENT_TEAM) after a fresh prebuild.
